قۆپچە / Qopcha — iOS demo IPA checklist
==========================================

Cannot build IPA on Windows. Use a Mac or Codemagic.

Bundle ID:  com.qopcha.Qopcha
Display:    قۆپچە
Version:    from pubspec.yaml (currently 1.0.0+1)

A) Mac + TestFlight (recommended for demos)
-------------------------------------------
1. Install Xcode, CocoaPods, Flutter; run: flutter doctor
2. Open: ios/Runner.xcworkspace
3. Runner → Signing & Capabilities → Team = your Apple Developer team
   (CODE_SIGN_STYLE is Automatic; do not commit .p12 / profiles)
4. App Store Connect → create app with bundle id com.qopcha.Qopcha
5. From repo root on Mac:
     chmod +x scripts/build_ios_demo_ipa.sh
     ./scripts/build_ios_demo_ipa.sh
6. Upload build/ios/ipa/*.ipa with Transporter (or altool)
7. App Store Connect → TestFlight → add internal/external testers

B) Ad Hoc IPA (registered devices only)
---------------------------------------
   ./scripts/build_ios_demo_ipa.sh --ad-hoc
   Uses ios/ExportOptions-AdHoc.plist

C) One iPhone plugged into a Mac (no IPA share)
----------------------------------------------
   flutter run --release -d <device>

D) No Mac — Codemagic
---------------------
1. Push repo to GitHub/GitLab; connect at https://codemagic.io
2. Enable Apple code signing (App Store Connect API key)
3. Build command: flutter build ipa --release
   (or run scripts/build_ios_demo_ipa.sh on their Mac image)
4. Publish artifact to TestFlight or download IPA

Export plists
-------------
  ios/ExportOptions-AppStore.plist  — TestFlight / App Store Connect
  ios/ExportOptions-AdHoc.plist     — Ad Hoc install

Never commit certificates, API keys, or provisioning profiles.
